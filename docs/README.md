# Процесс выполнения проектной практики

В ходе проектной практики была выполнена работа по изучению и освоению современных инструментов разработки программного обеспечения, а также приобретены навыки командной работы и ведения проектной документации.

Практика выполнялась в соответствии с заданием, размещённым в репозитории GitHub проекта. Основной задачей являлась разработка и сопровождение программного проекта с использованием системы контроля версий Git и платформы GitHub.

## Этапы выполнения практики

### 1. Ознакомление с заданием и структурой проекта

На начальном этапе было изучено техническое задание, структура репозитория, а также требования к содержанию отчётной документации. Были рассмотрены основные файлы проекта, включая `README.md`, каталоги с исходным кодом и отчётами.

### 2. Настройка рабочего окружения

Было выполнено подключение к репозиторию проекта, установка необходимого программного обеспечения и настройка среды разработки. Для работы использовались Git, GitHub и средства локальной разработки.

### 3. Изучение используемых технологий

В процессе практики были изучены основы работы с Git и GitHub:

- создание и клонирование репозиториев;
- работа с ветками;
- выполнение commit и push;
- разрешение конфликтов;
- оформление документации в формате Markdown.

### 4. Разработка и редактирование проекта

В рамках практики выполнялось редактирование файлов проекта, добавление новых материалов и изменение структуры документации. Также производилась работа с используемыми в проекте технологиями и инструментами разработки.

### 5. Ведение проектной документации

Важной частью практики стало оформление отчётных материалов и поддержание актуального состояния `README.md` проекта. Документация содержала описание целей проекта, этапов выполнения работы и полученных результатов.

### 6. Тестирование и проверка результатов

После внесения изменений проводилась проверка корректности работы проекта, анализ структуры файлов и исправление выявленных ошибок.

### 7. Подготовка итогового отчёта

На завершающем этапе были систематизированы результаты практики, оформлен итоговый отчёт и подготовлены материалы для сдачи.

## Полученные навыки

В ходе выполнения проектной практики были приобретены следующие навыки:

- работа с системой контроля версий Git;
- использование платформы GitHub для совместной разработки;
- ведение технической документации;
- работа с Markdown;
- организация структуры проекта;
- навыки командной разработки и планирования задач.

## Итоги практики

В результате прохождения проектной практики были закреплены теоретические знания и получен практический опыт разработки и сопровождения программных проектов. Выполненные задания позволили освоить современные инструменты разработки и получить представление о полном цикле работы над IT-проектом.
