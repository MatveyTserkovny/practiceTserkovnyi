# Процесс выполнения проектной практики

В ходе проектной практики была выполнена работа по изучению и освоению современных инструментов разработки программного обеспечения, а также приобретены навыки ведения проектной документации.

Практика выполнялась в соответствии с заданием, размещённым в репозитории GitHub проекта. Основной задачей являлась разработка и сопровождение программного проекта с использованием системы контроля версий Git и платформы GitHub.

## Этапы выполнения практики

### 1. Ознакомление с заданием и структурой проекта

На начальном этапе было изучено техническое задание, структура репозитория, а также требования к содержанию отчётной документации. Были рассмотрены основные файлы проекта, каталоги с исходным кодом и отчётами.

### 2. Настройка Git и репозитория

Были изучены основы работы с Git, а также создан репозиторий.

### 3. Ведение проектной документации

Важной частью практики стало оформление отчетных материалов в формате Markdown.

### 4. Создание статического веб-сайта

Далее был написан статический веб-сайт об основном проекте по дисциплине «Проектная деятельность».

Сайт вмещает в себя:
- Домашнюю страницу с аннотацией проекта.
- Страницу «О проекте» с описанием проекта.
- Страницу «Участники» с описанием личного вклада каждого участника группы в проект по «Проектной деятельности».
- Страницу «Журнал» с тремя постами о прогрессе работы.
- Страницу «Ресурсы» со ссылками на полезные материалы.

### 5. Выполнение вариативной части задания

Описание задания описано в [variable_task.md](https://github.com/MatveyTserkovny/practiceTserkovnyi/blob/main/task/variable_task.md)

В ходе выполнения задания был написан блокчейн на Java с хеш-функцией SHA-256.
На основе описания выполнения вариативной части задания был написан [статичейский веб-сайт](https://github.com/MatveyTserkovny/practiceTserkovnyi/blob/main/task/variable_task/presentation/index.html)

### 6. Подготовка итогового отчёта

На завершающем этапе были систематизированы результаты практики, оформлен итоговый отчёт и подготовлены материалы для сдачи.

## Полученные навыки базовой части

В ходе выполнения проектной практики были приобретены следующие навыки:

- работа с системой контроля версий Git;
- ведение технической документации;
- работа с Markdown;
- организация структуры проекта;
- основы разработки на Java;
- изучены основы криптографии.


## Итоги практики

В результате прохождения проектной практики были закреплены теоретические знания и получен практический опыт разработки и сопровождения программных проектов. Выполненные задания позволили освоить современные инструменты разработки и получить представление о полном цикле работы над IT-проектом.
